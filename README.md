# BELCEBÚ — Portfolio

Portafolio personal de BELCEBÚ, enfocado en configuración de Minecraft y desarrollo de plugins.

## Tecnologías / áreas
- Paper / Spigot
- Velocity
- Geyser / Floodgate
- Java / Python
- YAML
- MySQL
- Configuración de Networks

## Editar datos
1. Abre `index.html`.
2. Busca los textos que quieras cambiar.
3. Para Discord, reemplaza `REEMPLAZA_CON_TU_ID` por tu ID de usuario de Discord.
4. Puedes sustituir las imágenes dentro de `assets/`.

## Publicarlo en GitHub Pages
Crea un repositorio público y sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
Después entra en **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y `/ (root)` y guarda.

Tu página quedará en:
`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`
